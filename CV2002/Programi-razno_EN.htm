Script for exporting data from the DigiDvent supervisory system to Excel

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

The DigiDvent/DigiDb supervisory system stores measured values in a *.log file, which is written in binary form. The data therefore cannot simply be imported into Excel for further processing and analysis. The DigiDb database creates files on a weekly basis, separately for each parameter. A script was developed that reads all parameters from the folder where the data are stored and lists them in a dialog box as available for selection. The user then selects the individual parameters, the time range and the sampling time of the parameters, on the basis of which the data are imported into Excel, with the data of each parameter written to its own sheet.

Script for importing Barmag spinning plant data into Excel

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

The BARMAG spinning plant central data collection system (lines F and G) allows spinning parameters to be exported in *.csv format. Because the number of rows usually exceeds Excel's limit of 65,536 rows per sheet, and because the time format differs from the one Excel recognizes, simple or direct import of the data into Excel is not possible. The data have to be split into several parts already at the text-file level, and the time stamp has to be reformatted row by row, which is a rather time-consuming task. To automate the entry of data for the BARMAG spinning plant, a script was developed that reads the data written in the csv file, converts the time stamp and writes the data to an Excel file across several sheets if Excel's limit is exceeded.

Script for exporting data from the AxioVision program to Excel

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

AxioVision is a powerful commercial program for digital image analysis and processing from Carl Zeiss. At Julon it is used for the automated counting of filament capillaries and for determining the deviation of the capillary cross-section size from the average value. The automated measurement is set up with wizards that guide the operator step by step to the final goal. Despite the program's exceptional capability, it quickly proved too demanding for the average user (technician) of the textile laboratory, since it requires prior knowledge and familiarity with image processing procedures as well as a lot of experience in choosing the right image analysis parameters. In addition, the program does not allow a report on the performed measurement to be created easily. Consequently, a script for AxioVision was developed that presets the digital camera settings and most of the image processing parameters to optimal values, and then guides the operator with a wizard only through the key processing steps, whose settings allow an optimal analysis result with the minimum required knowledge on the part of the operator. In the last step the script allows the measured values, the image of the mathematically processed capillaries and the calculated values to be imported into an Excel file for the final report, which is kept in the digital archive. In this way the duration of the analysis was shortened considerably.

Script for plotting Toray spinning plant parameters in Excel

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

The Toray spinning plant supervisory system (extruders and spinning beam) stores each operating parameter separately on disk in a binary file. SCADA allows the diagram of an individual parameter to be plotted and reviewed up to a month back, but the supervisory system does not allow parallel comparison of arbitrary parameters with each other for the purpose of correlation and determining their mutual influence, or correlation with the parameters of the winding section. For this purpose a script was developed that reads the selected parameters stored in the binary file, converts them to ASCII form, imports them into an Excel file and plots a diagram. The data obtained in this way can be combined with each other for correlation and comparison purposes.

Script for importing measured data from the MainSMU supervisory system into Excel

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

The Toray winder supervisory system, named MainSMU, allows selected parameters of each winding position to be saved in the form of short or long trends, which are written to disk in a binary file. Long trends include up to four different parameters, which are written to the file every minute and serve for monitoring the operation of the winding position over a longer period. A short trend includes the values of six parameters, which are also acquired at higher speeds but with a limited measurement duration (a few hours), so this trend is intended for monitoring fast changes in the rewinding phase. Two different scripts were developed that import the data of one or the other trend into an Excel file and plot diagrams.

Program for servomotor control and communication with the supervisory computer


TARGERT USER:

Center for Experimental Mechanics (CEM) - master's thesis

DESCRIPTION:

The program is intended for controlling and monitoring the operation of a servomotor by computer. It includes a command protocol that enables communication with an external computer over the RS-232 serial communication interface. The program supports manual (analog) and computer (digital) control of servomotor operation. In manual control the servomotor responds to analog commands from a joystick connected to the analog inputs of the controller, while in computer control the controller responds only to commands and data received from the computer over RS-232 communication. The program allows the servomotor to run at a constant speed, at constant torque, and with sinusoidal variation of position or speed, as well as precise positioning and position reset. During operation the program continuously sends data on the current speed, position and torque to the supervisory computer. In addition, the program includes a further command protocol for controlling the servomotor over RS-232 by means of an ASCII terminal.

Mcservo.dpl
