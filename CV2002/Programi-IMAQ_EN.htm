A computer application for determining the rate of oxidation of polyamide under UV light


TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

A computer application enables determination of the degree of oxidation of polymer (polyamide) chips under UV light. The measuring is based on the fact that oxidized polyamide under UV light appears brighter then unoxidized. Analysis incorporates a computer vision, where a video camera (webcam) captures an image of the reference and measured sample simultaneously and software calculates color difference between two samples. Main feature of reference sample should be it retains its color properties under UV light over a longer period of time (several years). By comparing measured sample over the color stabile reference sample one can compensate any external influences such as accidental light intrusion, UV lamp color drift, drift of CCD sensor of camera, etc., which may arise during the measurement. From calculated color vectors of two samples and calculated difference of two vectors, software determines the degree of oxidation, which is represented as numeric value. Calculation is done in four different color spaces (RGB, XYZ, YUV, Lab) depending on operator's choice. Obtained values are stored into the database such as text file, Excel file or Access - MDB database. Before starting the measurement operator can choose or define a recipe for particular type of specimen (PA6, PA66, etc.). Recipe includes basic information about the test e.g. camera settings, color space, the name and location of the database / file storage, number of captured images to calculate the average value, size and position of the active area being analyzed of both reference and target sample, etc. The software allows captured image to be zoomed in or out depending on needs. Image area, which is not included in the calculation of the chromatic aberration, is painted as negative image for better identification of area. During the measurement all values​​ including calculated difference between the target vs. reference sample and standard deviation of values are printed on the screen. On completion the measured values are stored into the database for later post processing and historical overview.

Computer application for unidirectional optical strain measurement (video extensometer)

TARGERT USER:

Center for Experimental Mechanics (CEM), BASF

DESCRIPTION:

The application is developed for online optical displacement and/or strain measurement by means of CCD camera and video digitizer (frame grabber). The strain measurement is done on three specimens simultaneously while monitoring the temperature in the near vicinity of samples. The data on temperatures are received via RS232 serial communication from dedicated application Monitor.exe running on the nearby temperature monitoring system. The video extensometer application measures the distance between two parallel markers applied on the specimen surface and calculates strain upon the initial length. Sampling could be performed in linear or logarithmic timescale. Data on strain and temperature are plotted on the chart and written into data file for later analyses. Furthermore application also enables configuration of the frame grabber, receiving data packages on temperature over serial communication port and time synchronization against temperature monitoring computer.

Computer application for two dimensional optical strain measurement based on 2D FFT

TARGERT USER:

Center for Experimental Mechanics (CEM)

DESCRIPTION:

The computer software is dedicated for two-dimensional optical strain measurement by means of contrasting grid applied on the surface of the specimen. Image analysis is done by 2D FFT transformation of digital image obtaining the frequency in two perpendicular directions.  From obtained frequencies of unreformed (initial) and deformed grid the Lagrangian and/or Eulerian plane strains are calculated. The calculated values of the vertical, horizontal displacement and grid rotation as well as deformation epsx, epsz, epsxz including the main deformation eps1 and eps2 are written into database file. Software can grab image directly from CCD camera or it can load it from bitmap file stored on the disk. Vice versa (saving grabbed image as bitmap) is also possible for later processing.

Computer application for uni-directional displacement / strain measurement (simple videoextensometer)

TARGERT USER:

Center for Experimental Mechanics (CEM)

DESCRIPTION:

The simple DOS application designed to capture, store and analyze video images. Primarily developed as custom built video extensometer for universal testing machine ZWICK that would measure longitudinal strain and send measured value over RS232 communication to machine's supervision computer. By tracking the position of two distinctive marks applied on the surface of the specimen the image analysis algorithm determines the specimen elongation and uniaxial strain.  Different versions of application (Extensio.exe, Videoacq.exe) allow triggering and data transition ​​to the control computer via RS-232 communications.
