Remote reading of a gas meter

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

Multichannel pulse counter module type ADAM 6051 was selected for remote meter reading. This counter enables the connection of up to 12 digital pulse signals from any type of flow meter counter that generates pulse output signal for each unit of fluid. Total fluid counts are sent/accessed by user via LAN network. The module ADAM6051 has built-in web server that allows access of counter data via a regular web browser. A new java applet application intended to be run from the remote counter module was developed. The applet application is simply started by entering an IP address of the counter module into address line of a web browser. Configuration of the application enables defining a meaningful name of each meter counter. User interface shows cumulative total value, cumulative starting value and number of successive count since module started-up or reset of each individually defined counter value. Initial counter value can be remotely reset at any time logging with password and entering new initial counter value. Further more user interface also indicates validity status of each meter counter, which indicates whether reported values are correct or they may be desynchronized due to power failure.

Video surveillance of thermal oil plant

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

Some of the bad experiences of the thermal oil plant operation from the past fostered the introduction of remote video surveillance. Since the plant is dislocated from the energetic department the regular daily rounds of the personnel was practiced in the past. With introduction of video surveillance it is possible to on-line monitor thermal oil plant operation and immediate intervene in case of emergency. A web application was developed enabling monitoring of images provided by two remote cameras. The application allows zoom in and zoom out the image on the screen, by which some of important details could be resolved. Furthermore it enables capturing of individual images or videos and stores them locally on disk. Parallel to video signal from each camera also the audio is transferred; giving the operator a complete overview of the plant operation.
