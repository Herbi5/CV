A computer application for measuring capillary breaks and number of interlacing nodes of polyamide fibre

TARGERT USER:

Julon d.d., Aquafil S.p.A.

DESCRIPTION:

The application is intended to be used for continuous recording of capillary breaks and interlacing nodes obtained from measuring instrument FIBERSCAN FS. Measuring instruments continuously sends formatted data on the number of capillary breaks, number of interlacing nodes, filament speed, etc. via serial communication (RS232) into a computer. Application named as NodeScan reads received information and converts it into numerical values to be displayed. On measurement startup operator has to enter some basic information on test sample and measuring procedure such as the length of the test, test speed and file name, or it can select already predefined test the recipe. By pressing start button the application starts capturing data send by instrument and store it into database (text file). Meanwhile ​​obtained values are plotted in the chart and printed on the screen. When the predefined filament length elapses the measurement is automatically terminated and average values together with standard deviations are recorded as a report in the corresponding text file.

EXECUTABLE:

NodeScan.exe

HARDWARE:

Fibrescan FS 100
PC x86

SOFTWARE MODULES:

RS232 communication, graphic, sound, UI masks

PROGRAMMING LANGUAGE:

Visual Basic 6.0

OPERATING SYSTEM:

Windows 3.x, 95/98/NT

YEAR:

2004






A computer application for gravimetric measurements performed by METTLER TOLEDO AG245 scale

TARGERT USER:

Center for Experimental Mechanics (CEM), BASF

DESCRIPTION:

The application is used for continuous measurement of weight by means of Mettler Toledo scale. Apart from weight measurement software simultaneously records data on ambient temperatures by means of another computer that is running application called Monitor.exe. Data on ambient temperature and measured weight is transmitted via RS-232 communications and it is intercepted by application. Values are then printed on the screen and plotted on the chart as well as they are recorded into text file for further processing. Data sampling is done in linear or logarithmic time scale.

A computer application for temperature measurement by means of HP 3852 Data Acquisition

TARGERT USER:

Center for Experimental Mechanics (CEM), BASF

DESCRIPTION:

The software is designed to acquire simultaneously six temperatures data points from thermocouples type K, and one data point obtained by temperature sensor PT100. Thermocouples and PT100 are connected to the HP Data Acquisition system. Communication between accompanying computer and data acquisition is done via the HP-IB interface and command protocol. The application acquires measured values ​​of temperature and prints them on the screen as well as plots values in the chart. Average values ​​are also recorded in the text file for later processing. Since application is DOS based, it also enable to copy files to floppy disk, as well as it transfer individual values on temperatures (ambient temperature, and the specimen chamber) via RS-232 communications to another computer. It was design to be used in conjunction with the optical strain measurement application (Extensio.exe), where it is used to trigger the strain measurement on one hand and provides data on seven temperatures being measured on the other hand to the application Extensio.exe. The program allows the linear and logarithmic data acquisition.

EXECUTABLE:

Monitor.exe

HARDWARE:

Communication board HP82335 HP-IB
Data Acquisition HP 3852
PC x86

SOFTWARE MODULES:

RS232 communication, HP-IB (GP-IB) communication, graphic, sound, UI masks

PROGRAMMING LANGUAGE:

Miscosoft C

OPERATING SYSTEM:

DOS

YEAR:

1999-2000

Computer applications for data acquisition by HP 3421A multimeter


TARGERT USER:

Center for Experimental Mechanics (CEM)

DESCRIPTION:

Software is designed to obtain simultaneous measurement of four wire resistances (PT100 temperature probe - front panel connector) and voltage (load cell - force - back panel connection) by means of multi-meter. Measured values by multimeter are transmitted via HP-IB interface and HP-IB command protocol. Data on temperature, force, etc... is calculated from measured voltage and resistance and saved into text file. Individual versions of application (Volt_t.exe, Voltmet.exe, Volt_sv.exe) are extended by capability of capturing data on temperature via RS-232 communications received form Haake circulator.

A computer application for measuring the creep of polymer samples by HP 3457 multimeter

TARGERT USER:

Center for Experimental Mechanics (CEM)

DESCRIPTION:

Software is designed to simultaneously measure changes in thickness of the specimen by Linear Variable Differential Transformer ( LVDT sensor) connected to the front terminal board (front panel) of multimeter and temperature from PT100 sensor connected to the rear terminal board (rear panel) of multimeter. Data is transferred via HP-IB interface and HP-IB command protocol to PC. Software calculates creep strain from measured relative displacement at particular temperature and stores data into text file. Recalculation and chart printing is available at the end of measurement.

A computer application for measuring Poisson's ratio and tensile relaxation modulus

TARGERT USER:

Center for Experimental Mechanics (CEM) – Diploma thesis

DESCRIPTION:

Software is designed to simultaneously measure force by a load cell and change in thickness by LVDT sensor. Data from multimeter (measuring changes in thickness) and digital oscilloscope (measurement of load) are received via HP-IB interface and HP-IB command protocol. Application calculates Poisson's ratio and tensile modulus relaxation upon measured data and stores them into text file. Data recalculation and chart printing is enabled at the end of each measurement.

Poisson.bas(program teče v BASIC interpreterju – Q Basic)
